# 🚀 Multi-Agent Career Research & Intelligence System

An end-to-end multi-agent AI system built with **FastAPI**, **LangChain**, and **Streamlit** that automates deep-dive career research. The application searches domain-specific educational/professional databases, cleans and synthesizes live web data into an executive report, and provides a grounded conversational AI assistant to answer follow-up queries.

---

## 🌟 Key Features

* **Multi-Agent Orchestration:**
  * **Agent 1 (Search Agent):** Identifies valid career paths and fetches domain-specific search results using Tavily.
  * **Agent 2 (Scraper Agent):** Asynchronously scrapes web pages, strips boilerplate HTML tags, and extracts core content by using the BeautifulSoup Library.
  * **Agent 3 (Synthesis Agent):** Merges scraped content and structured context into a compact, high-density markdown research report.
* **Grounded Chatbot:** Powered by Llama-3 (Groq) to answer user questions strictly based on the generated report context.
* **Interactive UI:** Built using Streamlit, featuring real-time task status containers, clean markdown rendering, and interactive chat history.

---

## 🏗️ System Architecture

1. User enters the field.
2. Agent 1 uses the web_search tool to gather the urls from different sources.
3. Agent 2 uses those urls and then uses the tool web_scrape which uses BeautifulSoup to scrape text.
4. Agent 3 or just an LLM model creates a high density, well-formatted report using all the text.
5. The content generated by LLM model is fed into the groq model which interacts with user as a chatbot
   and answers strictly from the context.
---

## 🛠️ Tech Stack

* **Backend Framework:** FastAPI
* **Frontend Framework:** Streamlit
* **LLM Orchestration:** LangChain / LangChain Community
* **Models:**
  * Mistral AI (`mistral-small-latest`, `mistral-medium-latest`)
  * Groq (`llama-3.1-8b-instant`)
* **Search & Scraping:** Tavily Async Client, BeautifulSoup4
* **Validation & Data Models:** Pydantic
